# 구글 플레이 스토어 등록 정보

Play Console → 스토어 등록정보 → 기본 스토어 등록정보에 그대로 붙여 넣으세요.

## 앱 이름 (30자 이내)

```
도깨비 사주 - 기문둔갑 운세·작명·꿈해몽
```

※ 휴대폰 홈 화면 아이콘 밑 이름은 짧게 **도깨비 사주**로 나와요.

## 간단한 설명 (80자 이내)

```
생일만 넣으면 도깨비가 뚝딱! 기문둔갑 사주풀이, 오늘의 일진, 궁합, 작명증서, 꿈해몽까지
```

## 자세한 설명 (4000자 이내)

```
👹 도깨비 사주 — 기와 속 도깨비가 알려 주는 나의 운명

생년월일과 태어난 시만 넣으면, 옛 기와에 새겨진 도깨비가 기문둔갑(奇門遁甲)으로 당신의 운명을 풀어 드려요.
흔한 명리 사주가 아니라, 구궁(九宮) 판에 하늘과 땅의 기운을 펼쳐 보는 기문둔갑 홍국 방식이에요.

🔮 명국 — 타고난 내 운명
· 구궁도로 보는 나만의 운명 지도 (칸을 누르면 바로 풀이)
· 별점과 한 줄 판정으로 보는 성격·재물·직업·배우자·자녀·건강
· 재물운 전성기, 일이 크게 뜨는 시기, 결혼운이 강한 시기를 나이로 콕 짚어 드려요
· 사주로 보는 나의 기질 유형
· 🍀 행운 처방: 행운 색깔, 귀인 띠, 행운 방위, 행운 숫자, 행운 아이템

🎊 신수 — 올해 1년 운세
· 한 해 흐름과 달마다 좋은 달·조심할 달

☀️ 일진 — 오늘 하루 운세
· 매일 아침 원하는 시간에 오늘의 일진 알림

💞 궁합 — 둘의 인연
· 마음·생활·띠·오행으로 보는 두 사람 궁합 점수와 관계 팁

✍️ 작명 — 도깨비작명연구소
· 81수리 원형이정이 모두 좋은 이름 3개를 사주에 맞춰 추천
· 지금 이름 풀어 보기 (수리 길흉, 꺼리는 글자, 음양)
· 작명증서 1장 + 해석 1장을 PDF 파일로 바로 출력

🌙 꿈해몽
· 사람들이 가장 많이 꾸는 꿈 20가지 풀이
· 꿈 내용을 쓰면 맞는 해몽을 찾아 드려요

🙋 많이 묻는 질문 20
· 시험, 취업, 이직, 이사, 연애, 결혼, 재물… 내 사주로 바로 답해 드려요

🔒 개인정보 걱정 없이
· 입력한 생년월일은 휴대폰 안에서만 계산하고 서버에 저장하지 않아요
· 회원가입 없이 바로 쓸 수 있어요

※ 이 앱의 풀이는 전통 역학 원리를 바탕으로 한 참고용이에요. 중요한 결정은 스스로의 판단과 전문가 상담을 함께 고려해 주세요.
```
