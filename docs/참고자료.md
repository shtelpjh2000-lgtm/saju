# 참고 자료와 대조 기록

## 운곡 기문둔갑 프로그램 화면 (사용자 제공)
- 2026-11-12에 받은 프로그램 화면 16장(생일 15명). 이미지는 저장소(공개)에 넣지 않았어요.
- 생일 목록: `tests/screens-input.json`. 화면과 대조를 마친 명국 값: `tests/screens.json`(`node tests/make-fixture.js`로 생성).
- 대조 완료 항목: 국(치윤법·윤국), 태을구성, 생기복덕(15명) / 지반·천반 홍국수, 육친, 대운 나이(지반 중궁 五인 두 명 칸 전체) / 12운성(5명).
- 시간 보정은 화면 대조 때 −30분 기준.

## 앱에 아직 없는 프로그램 표시 (규칙 미확정)
- 칸 오른쪽 **두 번째 문 줄**: 轉盤(돌리기)·飛宮(날리기)·괘 뒤집기 모두 아님.
- 오른쪽 **대운별 신살 표**: 12신살 이름은 표준, 기준 지지와 나이별 지지 흐름이 사지와 안 맞음. 나이별 지지는 대략 (그해 + 10 + 음력 생월) mod 12 꼴이었으나 1984.3.11에서 어긋남.
- 칸마다 **작은 숫자 줄**: 중궁 값 c에서 궁마다 w10(c+궁번호). c는 사람·고른 해/달에 따라 다름(미확정).
- 칸의 작은 신살 글자(歲劫·日馬·桃宮·亡宮 등), 빨간 작은 표시(六父·二孫 등).
- 이걸 풀려면: 같은 사람의 성별만/시만 바꾼 화면, 또는 프로그램 도움말.
